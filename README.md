# ПР7. Ответы на контрольные вопросы

1. копия значения переменной. для int это само число, для обьекта класса это сслыка на обьект а не сам обьект.
2. ref переменная уже должна быть инициализированна и в методе может не изменятся, а out может быть не инициализированна до метода, но в нем обязательно должна присвоить значение.
3. потому что он сам создаёт и записывает результат, поэтому переменной не нужно иметь значение до вызова метода.
4. проблему лишнего копирывания структуры. если int маленький всего 4 байта, то если копирывать самы структуры которые могут быть на десятки полей тут уже последствия могут быть замтено дороже.
5. после обязательных.
6. они позволяют явно указать какому параметру передается значение, поэтому можно не соблюдать порядок параметров и пропускать необязательные.
